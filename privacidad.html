Política de privacidad

Aplicación: Ajuste de Cuentas · Última actualización: octubre de 2026

Qué es

Ajuste de Cuentas es una aplicación personal para registrar y analizar gastos. Es de uso individual: cada persona que la use conecta únicamente su propia cuenta de Gmail.

Qué datos de Google se solicitan

La aplicación pide un único permiso: acceso de solo lectura a Gmail (gmail.readonly). Nunca envía, modifica ni elimina correos.

Qué se lee y para qué

Solo se procesan los correos de notificación enviados por BCP, BBVA, Scotiabank y Yape. De cada uno se extraen únicamente el monto, la fecha y hora, el comercio o destinatario, los últimos cuatro dígitos de la tarjeta o cuenta, y el número de operación. Con esos datos se registra el movimiento para que su dueño pueda ver y analizar sus gastos. El resto del contenido de los correos no se guarda.

Dónde se guardan los datos

Los movimientos extraídos se guardan en una base de datos privada del propietario de la aplicación (Supabase / PostgreSQL), protegida con control de acceso por usuario. Las credenciales de acceso se guardan cifradas como secretos y no se incluyen en el código.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial de uso general.

Uso limitado de los datos de Google

El uso y la transferencia de la información recibida de las APIs de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso o borrar tus datos

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions. Para pedir que se borren los movimientos guardados, escribe al contacto indicado abajo.
